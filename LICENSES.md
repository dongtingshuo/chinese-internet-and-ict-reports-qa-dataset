# Record-level licenses — v2.1.0

This package uses mixed record-level licensing. No single license applies to the repository as a whole or to every source report. Follow each row's `publication_rights` and the matching entry in `sources.json`.

| Record license | Active and recommended records | Main obligations |
|---|---:|---|
| CC BY 3.0 IGO | 317 | Attribution, license link, and indication of adaptation where required. |
| CC BY 4.0 | 513 | Attribution and indication of changes for the QA records. |
| CC BY-SA 3.0 IGO | 54 | Attribution, adaptation notice, and ShareAlike for adapted records. |
| CC BY-NC-SA 3.0 IGO | 1,624 | Attribution, noncommercial use, adaptation notice, and ShareAlike for adapted records. |
| **Total** | **2,508** | Per-record terms apply. |

The recommended subset contains the same 2,508 records and therefore has the same license counts. The 1,107 v2.0 sentence-cloze rows are included in the CC BY-NC-SA 3.0 IGO count; third-party attribution screening for those pending candidates remains incomplete. The 508 v2.1 additions also retain their actual source license and attribution per row.

The 506 legacy CAICT QA records retain the CC BY 4.0 record license from the prior release. The dataset owner confirmed authorization to republish them. This does not assert that the underlying CAICT reports carry a CC BY 4.0 source license; those reports are not included.

Hugging Face metadata uses `license: other` for the mixed terms. Redistributors must keep each row's license, source attribution, adaptation notice, and source-specific terms together.
