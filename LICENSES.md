# Record-level licenses — v2.0.0

This package uses mixed record-level licensing. No single license applies to the repository as a whole or to every source report. Follow each row's `publication_rights` and the matching entry in `sources.json`.

| Record license | Active and recommended records | Main obligations |
|---|---:|---|
| CC BY 3.0 IGO | 317 | Attribution, license link, and indication of adaptation where required. |
| CC BY 4.0 | 513 | Attribution and indication of changes for the QA records. |
| CC BY-SA 3.0 IGO | 54 | Attribution, adaptation notice, and ShareAlike for adapted records. |
| CC BY-NC-SA 3.0 IGO | 1,116 | Attribution, noncommercial use, adaptation notice, and ShareAlike for adapted records. |
| **Total** | **2,000** | Per-record terms apply. |

The recommended subset has the same records and license counts as the active corpus. The 1,107 new cloze rows are included in the 1,116 CC BY-NC-SA 3.0 IGO rows. They contain short sentence excerpts and retain source attribution and license obligations; third-party attribution screening remains pending. The other nine rows under that license were present before this expansion.

The 506 legacy CAICT QA records retain the CC BY 4.0 record license from the prior release. The dataset owner confirmed authorization to republish them. This does not assert that the underlying CAICT reports carry a CC BY 4.0 source license; those source reports are not included.

Hugging Face metadata uses `license: other` for the mixed terms. Redistributors must keep each row's license, source attribution, adaptation notice, and source-specific terms together.
