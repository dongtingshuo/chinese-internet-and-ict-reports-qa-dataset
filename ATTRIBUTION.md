# Source Attribution

The packaged dataset is licensed under CC BY 4.0. Attribute the dataset, link to the license, and indicate changes. For each record, cite the original report identified by its `source_ids` and use the corresponding short-form attribution in `sources.json` and `source_refs`.

The original reports, PDFs, images, and other source media are not included in this package. This dataset license does not apply to those source files. The source bibliography, publisher names, official URLs, PDF hashes, attribution notices, and notice-page metadata are in `sources.json`.
