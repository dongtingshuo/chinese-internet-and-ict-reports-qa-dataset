# Citation

Please cite this dataset release as:

> Dong, T. (2026). *Chinese Internet and ICT Reports QA Dataset / 中文互联网与 ICT 报告问答数据集* (Version 2.1.0) [Dataset]. GitHub and Hugging Face. https://github.com/dongtingshuo/chinese-internet-and-ict-reports-qa-dataset

Version 2.1.0 contains 2,508 active records: the exact 2,000-record v2.0.0 corpus plus 508 source-reconstructed questions. All rows are in the recommended subset; cite the version and split/config used, and consult each record's `review_status`. The package does not claim human-reviewed gold status.

This repository contains a mixed-license dataset. No single license applies to every record or to the repository as a whole. For each record, follow its `publication_rights` and the corresponding entry in `sources.json`. See `LICENSES.md`, `LICENSE_STATUS.md`, and `ATTRIBUTION.md` for summaries. The 1,107 cloze rows retain their CC BY-NC-SA 3.0 IGO terms and pending review status. Historical CAICT QA records retain their prior record license under the dataset owner's republishing authorization; this does not assert a license for the underlying reports.

The exact 2,000-record v2.0.0 package remains under `history/v2.0.0/` and is also preserved unchanged in the active v2.1.0 corpus.
