> Dong, T. (2026). *Chinese Internet and ICT Reports QA Dataset / 中文互联网与 ICT 报告问答数据集* (Version 2.2.0) [Dataset]. GitHub and Hugging Face. https://github.com/dongtingshuo/chinese-internet-and-ict-reports-qa-dataset

Version 2.2.0 contains 2,355 records in the released Gold subset: 2,275 eligible records retained from v2.1.0 and 80 passing v2.2.0 replacement records. The split counts are TRAIN 1,573, DEV 372, and TEST 410. Baseline item IICR-V12-0030 is excluded for ambiguous question scope. Cite the version and split used.

The Gold label applies only to the released subset and reflects documented selection gates; it is not an external certification or a claim that every historical candidate is error-free. Human-review method disclosures are dataset-owner-attested rather than reviewer-signed. Historical splits are post-annotation, not blind holdouts.

The repository contains mixed record-level licenses. No single license applies to every record or source report. Preserve each record's publication_rights and the corresponding sources.json attribution. See LICENSES.md, LICENSE_STATUS.md, and ATTRIBUTION.md.
